Molecular structures for the ActiStruct-nebwalk TMC reliability benchmark.

- `initial_xyz/` — first-pass geometries (literature-informed guesses, not final references).
- `generated_candidates/` — local perturbation candidates for active learning.
- `optimized_xyz/` — QE-relaxed geometries parsed from `qe/outputs/relax/`.
- `neb_endpoints/` — endpoints prepared for the nebwalk demo (phase 2+ only).
