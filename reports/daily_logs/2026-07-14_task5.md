## Descriptor type clarification

The features in this benchmark are:
1. **Sorted Coulomb matrix eigenvalues** (Rupp et al. 2012, JCTC 8:1513):
   M_ii = 0.5·Z^2.4, M_ij = Z_i·Z_j/r_ij, sorted by descending |value|,
   zero-padded to 21 entries. Rotation and translation invariant by construction.
2. **Local metal-center geometric features**: n_ligands, M-L distances
   (mean/std/min/max), L-M-L angles (mean/std), C-O bond lengths (mean/std).

These are **NOT** RAC (Revised Autocorrelation) descriptors. The term "RAC
descriptors" appeared in earlier planning notes (daily_logs/2026-07-14_task4.md)
as a task label but is not claimed anywhere in the feature code or reports.
No code or report changes were needed for the labeling; the existing
`feature_report_v0.1.md` already correctly identifies the descriptor type.

## DFT vs reference bond lengths (primary systems)

All four primary DFT (PBE/90 Ry) M-L mean bond lengths underestimate
experimental reference values by 0.016–0.026 Å, consistent with PBE's
known tendency to underestimate TM-C bonds:

| System    | DFT M-L mean (Å) | Reference (Å)       | Diff (Å) | Within ±0.05? |
|-----------|------------------|---------------------|----------|----------------|
| cr_co6    | 1.900146         | 1.916 (Whitaker 1967) | −0.016 | ✓ |
| ni_co4    | 1.811869         | 1.838 (Hedberg 1979)  | −0.026 | ✓ |
| fe_co5    | 1.801269         | 1.829* (McClelland 2001) | −0.028 | ✓ |
| ferrocene | 2.043736         | 2.064 (Haaland 1968)  | −0.020 | ✓ |

*fe_co5 reference mean = (2×1.810 ax + 3×1.842 eq) / 5 = 1.829 Å

This systematic underestimation is expected and does not indicate an error.

## Ferrocene n_ligands caveat

`n_ligands = 10` for ferrocene counts all 10 Fe-C bonds (5 per Cp ring) within
the 2.5 Å cutoff. This is the correct M-C atom count for these descriptors.
Chemically, ferrocene has 2 ligands (two η⁵-Cp rings), but that concept is not
the basis of the Coulomb matrix or geometric feature computation. A test
explicitly documents this distinction.
