## Scientific meaning

1. **Recommended ecutwfc = 90 Ry** for all Fe-containing benchmark molecules.
2. Bond lengths (Fe-C axial and equatorial) are already converged at 60 Ry; the failure is
   purely in total energy — ~18.6 meV/atom at 60 Ry, ~4.4 meV/atom at 75 Ry vs 90 Ry.
3. All Fe-system DFT results from the original 60 Ry benchmark are flagged
   (`fe_cutoff_flag`) and must be re-run at 90 Ry before external citation.
4. 105 Ry was not needed: 75→90 Ry step is 4.4 meV, consistent with convergence; 90 Ry
   adopted as minimum acceptable.

## Bugs found and fixed

- **OpenMPI slot error** (`not enough slots for 4 processes`): WSL2 reports 3 physical cores;
  OpenMPI counted physical only (3 < 4). Fix: `mpirun --oversubscribe -np 4`.
- **`disk_io='low'` → no checkpoints on power cut**: QE writes nothing until completion.
  Fix: changed all input files to `disk_io='medium'`; added `restart_mode='from_scratch'`
  (batch auto-switches to `'restart'` when `.save` dir is non-empty).
- **Corrupted wavefunction on restart** (`error reading file .wfc1`): Previous interrupted
  run (105 Ry, pre-user-decision) left a partial 987 MB workdir.
  Fix: `rm -rf /home/duets/qe_workdirs/fe_co5_cutoff_105` before relaunch.
- **Batch stopped after 90 Ry despite convergence**: Old walltime check `exit 1` ran
  unconditionally after any run > 4h; 90 Ry took 9h07m (32861s).
  Fix: moved walltime exit into the non-convergence branch only; converged slow runs log
  `[WARN]` and continue.
- **Walltime regex missed `.` in `53m35.55s`**: Character class `[\dhms ]` lacked `.`.
  Fix: changed to `[\d.hms ]`.
- **pytest not found**: `python -m pytest` used system Python; `.venv` not activated.
  Fix: `source .venv/bin/activate && python -m pytest`.

## Known limitations

- 105 Ry was not run (user decision 2026-07-02); convergence between 90–105 Ry is unknown.
  Conservative assumption: 90 Ry is adequate, consistent with SSSP solid-state calibration.
- Convergence tested only on Fe(CO)5; not verified for ferrocene (also Fe-containing).
  Assumption: same element-level cutoff applies; acceptable until more data available.
- SSSP ecutwfc = 90 Ry was calibrated for bulk solid Fe, which is more demanding than
  gas-phase molecular Fe. 90 Ry is therefore conservative for molecular systems.
