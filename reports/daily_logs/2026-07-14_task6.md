## Key technical finding: max_force naming caveat

`max_force_ry_per_bohr` stored in the dataset is QE's `Total force` =
sqrt(sum_i sum_{α} |F_{i,α}|^2), NOT the per-atom maximum force. The QE
`forc_conv_thr = 0.0001 Ry/bohr` convergence criterion applies to the maximum
Cartesian force component on any single atom — a different quantity. As a result:

- Several systems appear to have `max_force_ry_per_bohr` > 0.0001 Ry/bohr:
  fe_co5 (1.09e-4), cr_co6__co_dist (1.50e-4), ferrocene__ring2_rotation (2.11e-4)
- All 16 systems are genuinely converged: QE output contains "bfgs converged"
  in all cases (confirmed from `convergence_status=converged`)
- The column name is misleading but the convergence data is correct
- A test now explicitly documents this to prevent future misinterpretation
